# Quickstart

```bash
bga ingest data/texts/the_hobbit.txt --title "The Hobbit"
bga pipeline full data/texts/the_hobbit.txt --title "The Hobbit"
bga generate scene -g "Bilbo agrees to leave the Shire" -c Bilbo -c Gandalf -p "Bag End" -o data/output/scene_001.json
```

You now have your first generated scene.
